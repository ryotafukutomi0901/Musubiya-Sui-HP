# 結び家SUI モック

2026-11-14 の CEO 指示で作ったモック。サイトは syodorin.org と同じレイアウト構成（アニメーションなし）で、`/admin/` に予約管理画面を付けた。静的な HTML・CSS・JavaScript だけで、ライブラリは使っていない。本番のコードではない。

同じ日の CEO 指示で、ページの分け方を要件定義書（`docs/REQUIREMENTS_2026-11-14.md`）と情報設計の案（`docs/INFORMATION_ARCHITECTURE.md`）に合わせて組み直した。見た目の部品は最初のモックのものを使っている。ピラティスのページは「新サイトでも載せる」場合の形で残した（`docs/CLIENT_QUESTIONS.md` A10）。

## 見方

このフォルダで次を実行して、http://localhost:4310/ を開く。管理画面は http://localhost:4310/admin/ 。ログイン画面のボタンを押せば入れる（何も送らない）。

```bash
python3 -m http.server 4310 --bind 127.0.0.1
```

社内では、プレビューの `musubiya-mock`（AI-Company 直下の `.claude/launch.json`）でも起動できる。文中の `docs/…` は社内の案件フォルダにある資料で、このリポジトリには入っていない。

2026-11-15 の CEO 指示で、レンタルスペースとピラティスの予約を「カレンダーで予約し、カレンダーで確かめる」形で動くようにした。ご予約のページと予約管理は `assets/mock-db.js` の同じ見本のデータを読み書きする。データはブラウザの localStorage に置くだけで、どこにも送らない。ご予約のページで申し込むと管理画面に出て、管理画面で承認すると、ご予約のページの確認画面に反映する（別のタブで開いていても描き直す）。メールは送らず、送る文面を画面と管理画面の「お客様へのお知らせ」に出している。日付が変わるか「見本のデータに戻す」を押すと、見本のデータに戻る。

## 作るときに守ったこと

- 写真の枠には、Instagram から借りた実写か、CEO が ChatGPT で作った生成画像を入れた（次の2節）。生成画像には左上に「イメージ（生成画像）」と出し、実写と見分けられるようにした。どちらもない枠は灰色の箱のままで、「写真：○○（撮影予定）」と書いてある。
- 文言と数字は `docs/CONTENT_SOURCE.md` から取った。分からないところは ○ にして、赤字の「※要確認」を付けた。公開前に必ず埋める。
- 予約と管理画面のデータはすべて表示例。フォームはどこにも送らない。
- 色・文字・余白は `docs/DESIGN.md` のトークンだけを使った。
- syodorin.org からは並び方と配置だけを借り、文章・画像・コードは使っていない。

## 公開版に進む前に決めること

- 見た目は syodorin.org の構成にかなり近い。公開版では配色・写真・見出しの組み方で差をつける。
- ヒーローのコピーは要件定義書のコンセプト「民家の小さな空間から、人と人がつながる場所を」をそのまま置いた。今のサイトの「日常から少し離れて、心と身体を整える場所」を残すか（B2）、「古民家」と名乗るか（A13）と一緒に決める。
- TOP に Instagram の投稿を自動で出すには、Instagram をプロアカウント（ビジネスかクリエイター）にして、Meta の連携の許可を取る。連携の鍵には期限があるので、自動で更新し、取れないときは前回の投稿を出し続ける作りにする。
- 管理画面は見た目と流れの見本。ログイン、保存、お客様への連絡、二重予約の確認は本番ではサーバー側で作る（`docs/WORK_SCHEDULE.html` の「人が書く部分」）。

## ファイル

- `assets/site.css`・`assets/site.js` — サイト共通の見た目と、ヘッダー・フッターの差し込み
- `assets/mock-db.js` — 予約の見本のデータと、空きの計算・お知らせの文面・カレンダー用ファイル（ご予約のページと予約管理で共有）
- `assets/reserve.js` — ご予約ページの動き（月のカレンダー、空きの表示、申込み、確認・変更・キャンセル）
- `assets/admin.css`・`assets/admin.js` — 管理画面
- `assets/img/` — 画像。実写・生成画像・Instagram の3つのフォルダに分けている（「画像の置き場所」の節）
- CSS と JS の読み込みに `?v=数字` を付けている。直したら数字を上げると、ブラウザが古いものを使わない
